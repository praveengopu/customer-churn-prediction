# Customer Churn Prediction

A learning-focused machine learning project using Python, Pandas, NumPy, and Scikit-learn.

## Dataset limitation
This project uses a synthetic dataset created for educational and portfolio demonstration purposes. It does not represent real customer data or real business outcomes.

## Workflow
1. Load and inspect the dataset
2. Split data into training and testing sets
3. Preprocess numerical and categorical features
4. Train Logistic Regression and Random Forest models
5. Evaluate accuracy, precision, recall, and F1-score
6. Save the evaluation results

## How to run

```bash
python -m pip install -r requirements.txt
python src/train_model.py
```
